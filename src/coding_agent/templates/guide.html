Coding Agent Guide

Open Workspace UI

What this tool does

Workspace-aware coding File + Git operations Test execution Approval workflow Semantic repository search
  • Understands requests conversationally and executes through registered tools.
  • Reads/creates/modifies/renames/deletes files inside workspace boundary.
  • Runs commands, runs tests, analyzes failures, and applies bounded repair strategies.
  • Provides dynamic /tools, /capabilities, /doctor, and /status reporting.

How to use

  1. Set your repo path in the left panel.
  2. Describe the task in the command box.
  3. Use Run Agent for workflow execution or Ask Only for guidance.
  4. Review plan, activity, tool timeline, and validation tabs while tasks run.
  5. For destructive actions, request and approve token in Destructive Approval Tokens panel.

Tip: Use the new one-click acceptance button in top bar to validate scenarios end-to-end.

Capabilities overview

  • File operations: read/create/write/edit/delete/rename/list/search.
  • Execution: safe command execution + auto test command detection.
  • Git: status, diff, log, branch operations, stage/commit with guardrails.
  • Intelligence: semantic index + repository structure/context analysis.
  • Governance: approval tokens for destructive actions and safety policies.
